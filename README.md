# Información
Proyecto de las olimpiadas obligatorias de la E.E.S.T. n.° 6 "Chacabuco" en Morón.

## Cómo probar
1. Instale Node.js y XAMPP
2. Clone este repositorio
3. Inicie los servidores de MySQL y Apache con XAMPP
4. Abra PHPMyAdmin y cree la base de datos `galloalerta`
5. Importe el archivo `galloalerta.sql` mediante PHPMyAdmin
6. Navegue hacia la carpeta `api` y ejecute el comando `node app.js` para iniciar el servidor de la API
7. Abra uno de los archivos HTML en su navegador
